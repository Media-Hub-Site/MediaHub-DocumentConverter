# 📄 MediaHub — Document Converter

Conversor de documentos standalone. Parte del ecosistema **Media Hub**.

## Conversiones soportadas
- PDF → Word (DOCX)
- PDF → Excel (XLSX)
- PDF → PowerPoint (PPTX)
- PDF → Imágenes (JPG)
- Word → PDF
- Excel → PDF
- PowerPoint → PDF
- HTML → PDF
- Imagen (JPG) → PDF

## Instalación
\\\powershell
pip install -r requirements.txt
\\\

## Ejecución
\\\powershell
python main.py
\\\
